# TERRA VIVA — publication quality gate

The public website is an **offline snapshot viewer**, not a live planetary simulation.
`validate_demo.py` checks expected assets, JSON structure, sample coherence and the viewer's snapshot reference.

Run `python validate_demo.py` before every public data update.
Successful validation cannot establish simulated consciousness, realistic human behavior, physical-world validity, novel science or security of any private simulation engine.

The original persistent engine and future source releases remain private. Public releases must exclude real personal data and unreviewed third-party copyrighted assets.
