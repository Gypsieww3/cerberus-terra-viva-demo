# C.E.R.B.E.R.U.S. — TERRA VIVA (demonstração pública)

Site: https://gypsieww3.github.io/cerberus-terra-viva-demo/

Esta pasta é uma **demonstração estática de consulta**, com globo visual,
cinco cidades, perfis fictícios, acontecimentos causais e um microbairro 2D
com participantes, pedras e formigas visualizadas, além de amostras de
investigações em matemática/física, engenharia de software e robótica.
O site apresenta uma comparação entre algoritmos A* e BFS e uma simulação
cinemática ideal de um robô diferencial. Não controla hardware nem valida
projetos reais.

O motor de simulação em Python, os ficheiros binários persistentes,
a base de dados local, os processos internos e a versão canónica em
desenvolvimento **não são publicados aqui**.

- O número de um milhão representa estados individuais compactos.
- O microbairro representa apenas um pequeno subconjunto localizado.
- Os dados de `snapshot.json` são uma fotografia do estado do simulador
  e não se atualizam sem uma nova publicação.
- O site não simula dor sentida, consciência ou cognição humana real.
- O código do presente repositório não tem licença aberta para reutilização:
  consultar [LICENSE.txt](LICENSE.txt).

Todos os seres humanos, nomes e acontecimentos representados são
inventados por algoritmos; não são dados de cidadãos reais.
